Pi Backup (rclone)

A personal, single-user backup tool.

Pi Backup is a private backup utility that runs on its owner's Raspberry Pi and uploads a copy of that machine's home directory to the owner's own Google Drive account, once a day, using rclone.

What it does

  • Copies files from the local machine to a folder in the owner's Google Drive.
  • Needs access only to the files it created itself: it requests the drive.file scope, so it cannot read, modify or delete anything else in the account.
  • Stores nothing on any third-party server; there is no backend service and no other user.
  • Is not distributed, published or offered as a service to anyone else — it is used by a single person, its author, on his own account.

Data handling

Files are transmitted directly from the Raspberry Pi to Google Drive over HTTPS. Credentials are kept locally on that machine. See the privacy policy for the details.
