Privacy Policy

Pi Backup (rclone) — last updated 3 November 2026

Pi Backup is a personal backup tool that runs on its owner's own computer. It is used by one person, on one Google account, and it offers no service to any other user.

What Google user data is accessed

The tool requests a single OAuth scope, https://www.googleapis.com/auth/drive.file. Under this scope Google grants access only to files and folders that the tool itself created. The tool cannot see, read, list, modify or delete any other file in the account — including files that already existed, or files created by other applications.

No Gmail, Calendar, Contacts, Photos or profile data is requested or used.

How the data is used

Files from the owner's computer are uploaded to a folder in the owner's own Google Drive, and read back only when the owner restores something or verifies that a backup is intact. The data is not analysed, aggregated, sold, shared, published or transferred to anyone.

Where the data goes

Directly from the owner's computer to Google Drive over HTTPS. There is no intermediate server, no proxy, and no third-party service involved. Nothing is stored outside the owner's Google account and the owner's own machine.

Storage of credentials

The OAuth token and client credentials are stored only on the owner's computer, in a file readable by its owner alone (permissions 600). They are never transmitted anywhere except to Google's own OAuth endpoints. The owner can revoke access at any time at myaccount.google.com/permissions.

Retention and deletion

Backups remain in the owner's Google Drive until the owner deletes them, either from the Drive web interface or from the tool. Deleting the files in Drive deletes them permanently; revoking the application's access stops all further transfers.

Limited Use disclosure

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
